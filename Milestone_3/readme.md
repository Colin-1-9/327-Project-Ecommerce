# Milestone 3

## Peer to Peer - E-commerce System



#### **Required Software:**



Python 3



========================================================

#### **Running the Demo:**



Open a terminal and run: 



python3 network.py



========================================================



#### **Files:**



##### **network.py**



Main Demonstration for the P2P e-commerce system.



Demonstrates:

* Join Behavior
* Leave Behavior
* Lookup requests routed through the mesh overlay
* Resource discovery through the P2P network



##### **peer.py**



The Peer class used by network.py



Implements:

* Peer Creation
* Neighbor Managment
* Join Protocol
* Leave Protocol
* Product Lookup Algorithm
